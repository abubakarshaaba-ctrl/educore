# EduCore Mobile Overhaul Colour Policy

The overhaul must preserve the existing EduCore visual identity.

## Core palette

- Navy is the primary brand colour for top bars, primary actions, selected navigation, headers, strong emphasis, and secure/authoritative states.
- White is the primary content surface and text-on-navy colour.
- Gold is the accent colour for highlights, selected accents, premium emphasis, important secondary actions, and brand details.

## Semantic colours

Green and red are not alternative brand colours. They are reserved for semantic states where they improve comprehension.

- Green: success, present, completed, active, valid, submitted, positive state.
- Red: error, absent, failed, destructive action, blocked state, urgent negative status.
- Amber/gold: warning, late, pending, attention required.

## UI rules

1. Do not introduce unrelated dominant colours into primary navigation or normal module cards.
2. Normal screens should read visually as navy + white + gold.
3. Green and red should appear only where the state has semantic meaning.
4. Avoid decorative use of red or green.
5. Keep contrast accessible on text, icons, badges, buttons, and status chips.
6. Tenant branding must not make core app navigation illegible or override critical semantic colours.
7. New components must use the existing EduCore design tokens instead of hard-coded colour literals wherever possible.

This policy applies to Phase B information architecture, Phase C native workspace completion, and Phase D visual redesign.
