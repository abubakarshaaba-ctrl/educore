# EduCore Quick Start: Curriculum-Aware Lesson Planning

## For Platform Super Admin

1. Go to **Academic Content Repository** in the Super Admin menu.
2. Upload a DOCX, text PDF, XLSX/XLS or ZIP.
3. Add subject, class level, topic and authority information.
4. Check that extraction is successful, then click **Activate**.

Only activated platform resources are available to lesson generation.

## For Teachers

1. Open **Lesson Planner → Create**.
2. Choose teaching class, subject, topic and any subtopics.
3. If needed, set **Curriculum Origin Level** and **Delivery Type**.
4. Click **Generate with AI**.
5. Edit the plan, then save as Draft or Publish.
6. Generate student notes from a published plan, edit them if needed, then save Draft or Publish.
7. Use Print for a PDF-ready copy.

## What to expect

EduCore searches the central repository by topic, subtopic, subject and level. It can use related lower-class prerequisite material for a higher-class lesson, but it never changes the teacher’s selected target class. Week selection is recorded on the plan and does not prevent relevant material from being found.
